# Bài 1 · SE Introduction
## Software
- = **programs + documentation**
- Loại sản phẩm
  - **Generic**: bán cho nhiều khách
  - **Custom**: một khách, theo spec của họ
- 3 cách tạo: **viết mới · cấu hình generic · reuse**
- Vai trò: kinh tế mọi nước phát triển phụ thuộc phần mềm
## Software tốt (4 thuộc tính)
- **Maintainability**: phải **evolve**
- **Dependability / Reliability**: **trustworthy**
- **Efficiency**: không lãng phí tài nguyên
- **Acceptability**: understandable, usable, **compatible**
  - Compatibility (user): version, environment
  - Portability (system): chuyển nền tảng ít sửa
## Chi phí
- Boehm '81: software ~15% → **~90%** tổng chi phí
- Software **> hardware**
- **Maintenance > development** (hệ thống sống lâu)
- **60% dev · 40% testing**
- Custom: **evolution > development**
- Mục tiêu: **cost-effective**
## Software Engineering
- **Engineering discipline**: theories, methods, tools
- Goals: **budget · on time · quality · customer needs**
- CHAOS 2020: **35% success · 46% challenged · 19% failed**
- So sánh
  - **CS**: lý thuyết, nền tảng
  - **SE**: thực tiễn, bàn giao
  - **System Eng.**: HW + SW + process (bao trùm SE)
## Xu hướng
- **Intelligent SE**: AI for SE · SE for AI systems
- **Low-code / No-code**: WordPress, Wix, Airtable, Shopify…
- **CI**: tích hợp code tự động, thường xuyên
- **CD**: tự động build, test, sẵn sàng release
- **DevOps**: văn hoá + practices + tools, rút ngắn SDLC
- **Agentic AI**
  - Completion → chat → **agent** (goal, plan, tools, iterate)
  - Kỹ sư: đặc tả, review, kiểm chứng, **vẫn chịu trách nhiệm**
  - Rủi ro: code sai, bảo mật, license/IP, lộ dữ liệu
## Software process
- = tập hoạt động phát triển / tiến hoá phần mềm
- 4 hoạt động
  - **Specification**: làm gì + ràng buộc
  - **Development**: design + code
  - **Validation**: đúng ý khách?
  - **Evolution**: thay đổi theo nhu cầu
- Process model = **biểu diễn đơn giản hoá** từ 1 góc nhìn
  - Workflow: trình tự
  - Data-flow: luồng thông tin
  - Role/action: **ai làm gì**
- Generic models: **Waterfall · Iterative · CBSE**
## Professional ethics
- Hơn cả **tuân thủ pháp luật**
- 4 vấn đề
  - **Confidentiality**
  - **Competence**: không nhận việc quá sức
  - **IP rights**: patent, copyright
  - **Computer misuse**
- ACM/IEEE Code (8)
  - **PUBLIC** · Client & Employer · Product
  - **JUDGMENT**: integrity, independence
  - Management · Profession · Colleagues
  - **SELF**: lifelong learning
